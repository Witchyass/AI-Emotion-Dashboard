# AI-Emotion-Dashboard
 This repository contains everything you need to explore public sentiment and emotional reactions to AI-generated art, using PySpark and Looker Studio.
 ---

## 📌 Project Summary

This project analyzes real social media comments about AI-generated art using PySpark. We applied NLP techniques to detect not just sentiment (positive, negative, neutral), but deeper **emotions** such as admiration, sarcasm, anger, and more.
